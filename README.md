# How to Film a Package Unboxing — Clear Evidence, Start to Finish

A single self-contained interactive HTML infographic (no build step, no backend). Open `index.html` in any browser.

A plain-language documentation guide: why to film your unboxing, setup before you start, the opening sequence, item-by-item documentation, quantity checks, damage evidence, keeping the original file, reporting issues, common mistakes, and a master checklist. Violet/fuchsia/cyan on dark, with light mode, sidebar navigation, and a rating quiz.

Educational reference only.
